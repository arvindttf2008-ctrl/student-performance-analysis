# Student Performance Analysis

## Project Overview
This project analyzes student academic performance using Microsoft Excel.

## Project Features
- Total marks calculation
- Automatic grade calculation
- Pass and fail analysis
- Attendance analysis
- Department-wise performance
- KPI dashboard
- Data visualization using charts

## Tools Used
- Microsoft Excel
- Excel Formulas
- Conditional Formatting
- Charts and Dashboard

## Dataset
This project contains 20 fictional student records created for learning and portfolio practice.

## Objective
To analyze student performance and present meaningful insights through an Excel dashboard.
